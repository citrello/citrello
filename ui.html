ChatGPT and Claude on the web

Use your library from ChatGPT, or from Claude in the browser and on your phone. Requests go through Citrello's secure bridge to the Citrello app on this computer, so Citrello needs to be running. Sign in above first.

Connector address: https://mcp.citrello.app/mcp

Add it to ChatGPT
  1. In ChatGPT open Settings → Apps & Connectors → Advanced settings and turn on Developer mode (paid plans).
  2. Back in Apps & Connectors, click Create. Name: Citrello. MCP server URL: the address above. Authentication: OAuth. Tick “I trust this application” and click Create.
  3. Sign in with the same email as here, and enter the code from the email.
  4. In a chat, click + → More → Developer mode and turn on Citrello. Then ask: “What's in my Citrello library?”
Add it to Claude on the web and phone
  1. On claude.ai open Settings → Connectors → Add custom connector.
  2. Name: Citrello. URL: the address above. Click Add, then Connect, and sign in with the same email.
  3. It then works on claude.ai, in the Claude phone apps, and in Claude Desktop too.

Requests from the web can save Word files only in Citrello's Documents folder.

Claude

Connect Citrello to the Claude desktop app. Claude can then search and add to your library in every chat, cite with [@Key] markers, and write Word documents with live citations.

Three quick steps (File Explorer or Finder is now showing Citrello.mcpb)
  1. In Claude Desktop, open Settings → Extensions.
  2. Drag Citrello.mcpb from File Explorer (Finder on Mac) onto that page.
  3. Click Install. Then ask Claude in a new chat: “What's in my Citrello library?”
Other ways to connect (advanced)

If the install window doesn't appear: in Claude Desktop open Settings → Extensions and drag Citrello.mcpb (next to Citrello.exe) onto it, or double-click that file.

(fallback: closes and restarts Claude Desktop; doesn't work with every Claude version)

Word

      
Adds a Citrello tab to Word:

      
    
        
  • Insert / Edit citation: a search dialog with your library (results update as you type); collect several references, add a page or a prefix (“see”), or “year only” for Smith et al. (2020). With the cursor in a citation, the same button edits it.
    • 
        
  • Update citations: renumbers and reformats every citation and the bibliography, turns [@Key] markers into citations, and drops citations whose text you deleted.
    • 
        
  • Citation style: pick the style for this document.
    • 
      

      
Everything happens inside the open document, so each action can be undone with Ctrl+Z.

      

      

        
        
      

      
Install by hand (if the button can't be installed automatically)
        
    
          
  1. Download Citrello.bas.
    2. 
          
  2. In Word press Alt+F11. In the left panel select Normal, then File → Import File… and choose Citrello.bas. Close the editor.
    3. 
          
  3. In Word: File → Options → Quick Access Toolbar, choose Macros, add CitrelloInsertNow, CitrelloUpdateNow and CitrelloStyleNow, OK.
    4. 
          
  4. Click the new toolbar buttons to insert citations or update the open document. (The manual version uses simple input boxes instead of the search dialog.)
