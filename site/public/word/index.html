Citrello for Word

Cite from your Citrello library without leaving Word. Type “Wang et al.” and Citrello offers Wang's papers. Click a citation to see the papers in it, add more or take one out. Any citation style, and a reference list that keeps itself up to date.

  • Your library comes with you. Sign in with your Citrello email: the add-in uses your Citrello cloud copy (turn it on by signing in to the web app).
  • Documents travel. Each citation keeps its paper's details inside the document, so it still works on a co-author's computer, and Citrello's “Check and fix” reads it.
  • Coming next: “Find me a new paper” and “Check this citation” with Claude (Citrello Pro), and the add-in in Microsoft's add-in store.

Word on the web

Works with any Microsoft account, on any computer.

  1. Download Citrello's add-in file.
  2. Open a document in Word on the web (office.com).
  3. On the Home tab, click Add-ins, then More Add-ins.
  4. Click My Add-ins, then Upload My Add-in (top right), choose the file and click Upload.
  5. Citrello's lemon appears on the Home tab. Click it to open the panel.

Word on a Mac

  1. Download Citrello's add-in file.
  2. Quit Word.
  3. In Finder, press Shift + Command + G, paste ~/Library/Containers/com.microsoft.Word/Data/Documents/wef and press Return (create the wef folder if it isn't there).
  4. Move the downloaded file into that folder.
  5. Open Word, then Home tab → Add-ins (or Insert → My Add-ins) and pick Citrello.

Word on Windows

Works even when “More Add-ins” is greyed out (common with university accounts).

  1. Close Word.
  2. Click Start, type PowerShell and open Windows PowerShell (no administrator rights needed).
  3. Paste this line (right-click pastes) and press Enter. It downloads Citrello's add-in file to your user folder and tells Word where it is; you should see Done. 
    $f="$env:USERPROFILE\Citrello-Word-addin.xml"; Invoke-WebRequest https://citrello.app/word/manifest.xml -OutFile $f; New-Item -Path HKCU:\Software\Microsoft\Office\16.0\WEF\Developer -Force | Out-Null; Set-ItemProperty -Path HKCU:\Software\Microsoft\Office\16.0\WEF\Developer -Name Citrello -Value $f; "Done"
  4. Open Word: Home → Add-ins, then Citrello under My Add-ins.

To remove it: Remove-ItemProperty -Path HKCU:\Software\Microsoft\Office\16.0\WEF\Developer -Name Citrello

“More Add-ins” is greyed out?

Word turns add-ins off in two cases. Check them in this order.

  1. A privacy setting is off. In Word: File → Account → Account Privacy → Manage Settings, tick Turn on optional connected experiences, click OK, then close and reopen Word.
  2. Your university or employer turned add-ins off for its accounts (common). Use Word on the web with a personal Microsoft account instead: sign out at office.com, sign in with a free personal account (Outlook, Hotmail or a new one), open your document there and follow the Word on the web steps.
  3. On Windows, another way in: make a folder (for example C:\CitrelloAddin) and put the add-in file in it. Right-click the folder → Properties → Sharing → Share… → Share, and copy the network path it shows (like \\YOUR-PC\CitrelloAddin). In Word: File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs, paste the path into Catalog Url, click Add catalog, tick Show in Menu, click OK and restart Word. Then Home → Add-ins → Advanced (or Insert → My Add-ins) → Shared Folder → Citrello.

First time

  1. The panel takes 10–30 seconds to open the first time (Citrello's engine loads in Word).
  2. Sign in with the email you use in Citrello and type the code we send you.
  3. Pick your citation style at the top. Put the cursor where the citation goes and press Cite.
  4. Press Insert the reference list where your references go. It updates as you cite.
