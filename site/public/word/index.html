Citrello for Word

Cite from your Citrello library without leaving Word. Type “Wang et al.” and Citrello offers Wang's papers. Click a citation to see the papers in it, add more or take one out. Any citation style, and a reference list that keeps itself up to date.

  • Your library comes with you. Sign in with your Citrello email: the add-in uses your Citrello cloud copy (turn it on by signing in to the web app).
  • Documents travel. Each citation keeps its paper's details inside the document, so it still works on a co-author's computer, and Citrello's “Check and fix” reads it.
  • Coming next: “Find me a new paper” and “Check this citation” with Claude (Citrello Pro), and the add-in in Microsoft's add-in store.

Word on the web

Works with any Microsoft account, on any computer.

  1. Download Citrello's add-in file.
  2. Open a document in Word on the web (office.com).
  3. On the Home tab, click Add-ins, then More Add-ins.
  4. Click My Add-ins, then Upload My Add-in (top right), choose the file and click Upload.
  5. Citrello's lemon appears on the Home tab. Click it to open the panel.

Word on a Mac

  1. Download Citrello's add-in file.
  2. Quit Word.
  3. In Finder, press Shift + Command + G, paste ~/Library/Containers/com.microsoft.Word/Data/Documents/wef and press Return (create the wef folder if it isn't there).
  4. Move the downloaded file into that folder.
  5. Open Word, then Home tab → Add-ins (or Insert → My Add-ins) and pick Citrello.

Word on Windows

  1. Download Citrello's add-in file.
  2. In Word, Home tab → Add-ins → More Add-ins → My Add-ins.
  3. If you see Upload My Add-in, choose the file. If you don't (some versions hide it), use Word on the web until Citrello is in Microsoft's store, or the Citrello tab that comes with Citrello for Windows.

First time

  1. The panel takes 10–30 seconds to open the first time (Citrello's engine loads in Word).
  2. Sign in with the email you use in Citrello and type the code we send you.
  3. Pick your citation style at the top. Put the cursor where the citation goes and press Cite.
  4. Press Insert the reference list where your references go. It updates as you cite.
